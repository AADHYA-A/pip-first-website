Drop the official Pip asset pack images here, then set their file names in ../config.js (ASSETS).
Nothing in this folder is loaded unless config.js names it, so an empty folder causes no console errors.

Suggested mapping:
  Pip Waving on Cloud           -> wave      (floats near the cursor on desktop)
  The Lullaby Lab Music Box     -> musicBox  (Lullaby Lab card)
  Dream Nightlight Lantern      -> lantern   (Nightlight Collection card)
  Pip Studio Character Portrait -> portrait  (beside the Growth Chart)
